# bankco-native-sdk

React Native SDK for embedding the Bankco web flow inside a host mobile application.

## Install

```bash
npm install bankco-native-sdk
npx expo install react-native-webview
```

You can also install directly from GitHub:

```bash
npm install github:VickyAdneto/bankco_native_sdk
```

## Usage

```jsx
import { View } from 'react-native';
import BankcoSdkView from 'bankco-native-sdk';

export default function RewardsScreen() {
  return (
    <View style={{ flex: 1 }}>
      <BankcoSdkView
        url="https://rewards.bankco.co.in"
        token="your_backend_token"
        cardId="card_123"
      />
    </View>
  );
}
```

## Integration Model

- The host app creates the screen or container.
- `BankcoSdkView` fills the available parent space.
- The host app owns navigation, headers, safe area handling, and route placement.
- Use a dedicated screen with `flex: 1` when you want a full-screen SDK experience.

## Props

- `url`: Base Bankco URL
- `token`: Backend-issued token
- `cardId`: Optional card identifier
- `debug`: Optional boolean to show SDK diagnostics during integration
- `timeoutMs`: Optional load timeout in milliseconds. Default is `15000`
- `onLoadStateChange`: Optional callback for load, navigation, and timeout events
- `onError`: Optional callback for WebView, HTTP, and timeout errors

## URL Behavior

The SDK automatically builds the final URL by appending:

- `token=<token>`
- `mod=mobsdk`
- `card_id=<cardId>` when `cardId` is provided

Example:

```text
https://rewards.bankco.co.in?token=<token>&mod=mobsdk&card_id=<cardId>
```

## Notes

- Pass the base Bankco URL in `url`, not a fully assembled URL.
- The token should be generated by your backend, not hardcoded in the app.
- The SDK is intended for Android and iOS React Native apps.
- The SDK does not create or push its own native screen automatically.
- Browser embedding may be blocked by site security headers even when native WebView works.

## Publish

Publish from the repo root:

```bash
npm login

```
